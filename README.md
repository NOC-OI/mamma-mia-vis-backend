# mamma-mia-vis-backend
Backend API which glider/ALR trajectory, metrics readings like nitrate, phosphate, pressure, salinity, silicate and temperature.

# API endpoints documentation
To access interactive API docs go to http://127.0.0.1:8040/docs

# Run backend API locally
To run backend API locally, run the following command:
```bash
% uvicorn main:app --reload --port 8040
```
