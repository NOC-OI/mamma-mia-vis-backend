# API Reference

The MAMMA-MIA Visualization Backend provides FastAPI endpoints for querying and reading Zarr oceanographic datasets.

## Interactive API Documentation

When running the application, interactive documentation generated by Swagger UI and ReDoc is available:

- **Swagger UI**: `http://127.0.0.1:8040/docs`
- **ReDoc**: `http://127.0.0.1:8040/redoc`

---

## Core Endpoints

### 1. Dataset Variables
Returns a list of data variables available in a specified Zarr dataset URL and group.

- **URL**: `/zarr_variables`
- **Method**: `GET`
- **Query Parameters**:
  - `url` (string, required): Dataset URL or local store path.
  - `group` (string, optional): Zarr group to inspect.
- **Response**: `JSON` list of variable strings.

---

### 2. Dataset Dimensions
Returns dimensions and their shapes for a specified Zarr dataset.

- **URL**: `/zarr_dimensions`
- **Method**: `GET`
- **Query Parameters**:
  - `url` (string, required): Dataset URL or local store path.
  - `group` (string, optional): Zarr group to inspect.
- **Response**: `JSON` object mapping dimension names to shapes.

---

### 3. Time Values
Returns time values for a specified Zarr dataset.

- **URL**: `/zarr_time_values`
- **Method**: `GET`
- **Query Parameters**:
  - `url` (string, required): Dataset URL or local store path.
  - `group` (string, optional): Zarr group to inspect.
- **Response**: `JSON` list of time value strings.

---

### 4. Trajectory Data (CZML)
Returns CZML JSON structure containing datetime, latitude, longitude, and depth for an AUV's trajectory.

- **URL**: `/zarr_trajectory`
- **Method**: `GET`
- **Query Parameters**:
  - `url` (string, required): Dataset URL or local store path.
  - `payload_group` (string, optional): Zarr group to get AUV's trajectory data.
  - `platform_group` (string, optional): Zarr group to get AUV's platform data.
  - `platform_model_name` (string, optional): Attribute to get AUV's platform model name.
  - `start_date` (string, optional): Start date to filter AUV's trajectory data.
  - `end_date` (string, optional): End date to filter AUV's trajectory data.
- **Response**: `JSON` CZML object containing position and orientation metrics.

---

### 5. Trajectory Data (CSV)
Returns trajectory data (id, latitude, longitude, depth) in CSV format as a file download.

- **URL**: `/zarr_trajectory_csv`
- **Method**: `GET`
- **Query Parameters**:
  - `url` (string, required): Dataset URL or local store path.
  - `payload_group` (string, optional): Zarr group to get AUV's trajectory data.
  - `platform_group` (string, optional): Zarr group to get AUV's platform data.
  - `platform_model_name` (string, optional): Attribute to get AUV's platform model name.
  - `start_date` (string, optional): Start date to filter AUV's trajectory data.
  - `end_date` (string, optional): End date to filter AUV's trajectory data.
  - `target_depth_format` (string, optional): Format to return depth values, either `'Mean Sea Level'` or `'WGS84 Ellipsoid'`.
- **Response**: `text/csv` file attachment (`trajectory.csv`).

---

### 6. Sensor Metrics
Returns datetime, latitude, longitude, depth, conductivity/salinity, temperature, pressure, and chlorophyll values.

- **URL**: `/zarr_metrics`
- **Method**: `GET`
- **Query Parameters**:
  - `url` (string, required): Dataset URL or local store path.
  - `reality_group` (string, optional): Zarr group to inspect to get sensor readings.
  - `start_date` (string, optional): Start date to filter sensor readings.
  - `end_date` (string, optional): End date to filter sensor readings.
- **Response**: `JSON` object containing time series of sensor metric readings.

---

### 7. Metrics Units
Returns measurement units for conductivity, salinity, temperature, pressure, and chlorophyll levels.

- **URL**: `/zarr_metrics_units`
- **Method**: `GET`
- **Query Parameters**:
  - `url` (string, required): Dataset URL or local store path.
  - `attributes_group` (string, required): Zarr group to inspect to get sensor readings units from attributes.
  - `second_sensor` (string, required): Sensor name of AUV reading conductivity/salinity, temperature, and pressure values.
  - `third_sensor` (string, required): Sensor name of AUV reading chlorophyll levels.
- **Response**: `JSON` object mapping metric names to unit strings.

---

### 8. Mission Deployments
Returns mission deployments contained within the Zarr dataset.

- **URL**: `/zarr_mission_deployments`
- **Method**: `GET`
- **Query Parameters**:
  - `url` (string, required): Dataset URL or local store path.
- **Response**: `JSON` object detailing mission deployments.

---
